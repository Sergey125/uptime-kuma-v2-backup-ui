# Uptime Kuma v2 Backup & Restore Web UI

Простой и легковесный веб-интерфейс для экспорта и импорта резервных копий конфигураций (в формате JSON) для **Uptime Kuma v2.x**.

---

## 📌 Зачем это нужно?

Начиная с версии **Uptime Kuma 2.0+**, разработчики полностью переработали архитектуру и временно убрали из веб-панели функцию создания и восстановления резервных копий через JSON (`Settings` -> `Backup`). Единственным официальным способом остался полный бэкап папки данных `kuma.db`.

Однако при переустановке, переносе или миграции со старых версий (1.x) часто на руках остаётся только сохранённый файл `backup.json`. 

Этот микросервис решает данную проблему:
* Подключается к работающему серверу Uptime Kuma v2 через его Socket.IO / REST API.
* Позволяет **в один клик выгрузить** текущий список мониторов и уведомлений в JSON.
* Позволяет **загрузить файл JSON** (включая бэкапы от версии 1.x), автоматически воссоздав все ваши мониторы в Uptime Kuma v2 без ручного переноса.

---

## ✨ Возможности

- ⬇ **Резервное копирование (Экспорт):** мгновенная выгрузка структуры мониторов и параметров уведомлений в `.json` файл.
- ⬆ **Восстановление (Импорт):** чтение JSON-файлов резервных копий (поддерживает формат v1 и v2) и пакетное добавление мониторов через API.
- 🐳 **Полная контейнеризация:** готов к запуску через Docker Compose и отлично интегрируется в панель управления **Dockge**.
- 🔒 **Безопасность:** учетные данные не сохраняются на сервере, а используются исключительно во время активной сессии API-запроса.

## 🚀 Быстрый старт

### Вариант 1. Запуск через Docker Compose (в терминале)

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git](https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git)
   cd uptime-kuma-v2-backup-ui
Соберите и запустите контейнер:

Bash
docker compose up -d --build
Откройте веб-интерфейс в браузере:

http://localhost:8080
(или http://<IP-адрес_сервера>:8080)

Вариант 2. Развертывание в панели Dockge
Скопируйте папку с проектом в директорию ваших стеков (по умолчанию /opt/stacks):

Bash
git clone [https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git](https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git) /opt/stacks/kuma-backup-tool
Перейдите в интерфейс Dockge (http://localhost:5001).

В списке стеков слева появится kuma-backup-tool.

Нажмите кнопку Deploy (или Update).

📖 Как пользоваться
Откройте страницу инструмента (http://localhost:8080).

В форме заполните:

URL Uptime Kuma:

Если Uptime Kuma крутится на том же хосте в Docker: используйте http://host.docker.internal:3001 или локальный IP хоста (например, http://192.168.1.50:3001).

Если на другом сервере: укажите его внешний или доменный адрес (например, http://kuma.example.com).

Логин / Пароль: учетные данные учетной записи администратора в Uptime Kuma.

Для экспорта: нажмите зеленую кнопку «⬇ Скачать Backup (.json)» — браузер сразу скачает готовый файл.

Для импорта: в нижней секции выберите ваш .json файл и нажмите синюю кнопку «⬆ Загрузить и восстановить».

🛠 Стек технологий
Backend: Python 3.12, FastAPI, Uvicorn

API клиент: uptime-kuma-api

Окружение: Docker (Debian/Alpine-slim)
