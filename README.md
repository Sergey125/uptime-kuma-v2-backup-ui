# Uptime Kuma v2 Backup & Restore Web UI

A lightweight web tool to **export and import Uptime Kuma v2 monitor backups (JSON)** via its API — no manual `kuma.db` handling required. Docker & [Dockge](https://github.com/louislam/dockge) ready.

Простой и легковесный веб-интерфейс для экспорта и импорта резервных копий конфигураций (в формате JSON) для **Uptime Kuma v2.x**.

---

## 📌 Зачем это нужно?

Начиная с версии **Uptime Kuma 2.0+**, разработчики полностью переработали архитектуру и временно убрали из веб-панели функцию создания и восстановления резервных копий через JSON (`Settings` → `Backup`). Единственным официальным способом остался полный бэкап папки данных `kuma.db`.

Однако при переустановке, переносе или миграции со старых версий (1.x) часто на руках остаётся только сохранённый файл `backup.json`.

Этот микросервис решает данную проблему:
* Подключается к работающему серверу Uptime Kuma v2 через его Socket.IO / REST API.
* Позволяет **в один клик выгрузить** текущий список мониторов и уведомлений в JSON.
* Позволяет **загрузить файл JSON** (включая бэкапы от версии 1.x), автоматически воссоздав все ваши мониторы в Uptime Kuma v2 без ручного переноса.

---

## ✨ Возможности

- ⬇ **Резервное копирование (Экспорт):** мгновенная выгрузка структуры мониторов и параметров уведомлений в `.json` файл.
- ⬆ **Восстановление (Импорт):** чтение JSON-файлов резервных копий (поддерживает формат v1 и v2) и пакетное добавление мониторов через API.
- 🐳 **Полная контейнеризация:** готов к запуску через Docker Compose и отлично интегрируется в панель управления **Dockge**.
- 🔒 **Безопасность:** учётные данные не сохраняются на сервере, а используются исключительно во время активной сессии API-запроса.

## 🚀 Быстрый старт

Есть два способа запустить инструмент. Если у вас уже есть **Dockge** — используйте Вариант 1, это проще всего.

### Вариант 1. Через Dockge (рекомендуется, без клонирования репозитория)

1. Откройте Dockge (`http://<IP-адрес_сервера>:5001`).
2. Нажмите **+ Compose** → **New Stack**.
3. Задайте имя стека, например `kuma-backup-tool`.
4. Скопируйте и вставьте в редактор ровно этот `compose.yaml`:

   ```yaml
   services:
     kuma-backup:
       build: https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git
       image: kuma-backup-tool:latest
       container_name: kuma-backup-tool
       restart: unless-stopped
       ports:
         - "8080:8080"
       extra_hosts:
         - "host.docker.internal:host-gateway"
       environment:
         - KUMA_URL=http://host.docker.internal:3001
   ```

5. Нажмите **Deploy**. Docker сам скачает исходники с GitHub и соберёт образ — клонировать репозиторий вручную не нужно.
6. Откройте `http://<IP-адрес_сервера>:8080`.

### Вариант 2. Через Docker Compose в терминале (с клонированием репозитория)

```bash
git clone https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git
cd uptime-kuma-v2-backup-ui
docker compose up -d --build
```

Откройте `http://localhost:8080` (или `http://<IP-адрес_сервера>:8080`).

> **Старая версия Docker (без плагина `compose`)?**
> Если команда `docker compose` не найдена, но установлен отдельный бинарник `docker-compose` (Compose v1), используйте его через дефис — команды идентичны:
> ```bash
> git clone https://github.com/Sergey125/uptime-kuma-v2-backup-ui.git
> cd uptime-kuma-v2-backup-ui
> docker-compose up -d --build
> ```

## 🔄 Обновление

> Файлы приложения копируются **внутрь образа во время сборки**, поэтому одного `git pull` недостаточно — образ нужно пересобрать.

**Если стек развёрнут через Dockge (Вариант 1):**
Просто нажмите кнопку **Update** (или **Deploy** заново) в интерфейсе Dockge — она сама скачает актуальную версию с GitHub и пересоберёт контейнер.

Если после обновления код визуально не изменился — Docker мог закэшировать старую версию. В этом случае в консоли на сервере выполните:
```bash
docker compose build --no-cache
docker compose up -d
```

**Если стек развёрнут через `git clone` (Вариант 2):**
```bash
cd uptime-kuma-v2-backup-ui
git pull
docker compose up -d --build
```
(на старом Compose v1 — те же команды, но `docker-compose up -d --build`)

## 📖 Как пользоваться

1. Откройте страницу инструмента: `http://<адрес_сервера>:8080`.
2. Заполните форму:
   - **URL Uptime Kuma** — адрес вашего сервера Uptime Kuma:
     - Если Uptime Kuma запущена в Docker на том же хосте: `http://host.docker.internal:3001` или локальный IP хоста (например, `http://192.168.1.50:3001`).
     - Если на другом сервере: укажите его внешний или доменный адрес (например, `http://kuma.example.com`).
   - **Логин / Пароль** — учётные данные администратора Uptime Kuma.
3. **Для экспорта:** нажмите зелёную кнопку «⬇ Скачать Backup (.json)» — браузер сразу скачает готовый файл.
4. **Для импорта:** в нижней секции выберите ваш `.json` файл и нажмите синюю кнопку «⬆ Загрузить и восстановить».

> ⚠️ Логин и пароль передаются в открытом виде в теле запроса. Не открывайте порт 8080 напрямую в интернет — держите инструмент в локальной сети или за VPN/reverse-proxy с HTTPS.
